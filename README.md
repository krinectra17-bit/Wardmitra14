# वार्डमित्र 14 (WardMitra 14) — श्रीमती पूजा मनीष दाधीच

> **वार्ड नंबर 14, भारतीय जनता पार्टी (भाजपा)**  
> **सेवा | सुशासन | विकास**  
> आधिकारिक नागरिक सेवा एवं जनसंवाद पोर्टल

---

## 📖 परिचय

यह पोर्टल वार्ड नंबर 14 के सम्मानित नागरिकों की समस्याओं, सुझावों एवं स्थानीय विकास प्राथमिकताओं को सीधे जन-प्रतिनिधि एवं संबंधित नगर निकाय तक पहुंचाने के लिए विकसित किया गया एक आधुनिक, पारदर्शी एवं सुरक्षित वेब मंच है।

---

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **आर्ट-डायरेक्टेड एडिटोरियल हीरो (Editorial Hero)**:
   - प्रत्याशी परिचय, वार्ड विवरण एवं सीधा समस्या निवारण विकल्प।
   - मोबाइल एवं डेस्कटॉप के लिए अनुकूलित रिस्पॉन्सिव लेआउट।

2. **नागरिक समस्या निवारण पोर्टल (Citizen Issue Reporting - `/report`)**:
   - सड़क, नाली, पेयजल, प्रकाश, सफाई एवं अन्य स्थानीय समस्याओं को सीधे दर्ज करने की सुविधा।
   - फोटो अपलोड एवं लोकेशन विवरण।
   - स्वचालित संदर्भ संख्या (Unique Reference ID): `WARD14-XXXXXX`।
   - व्हाट्सएप (WhatsApp) पर एक क्लिक में समस्या साझा करने की सुविधा।

3. **पारदर्शी समस्या ट्रैकर (Issue Tracking - `/track`)**:
   - रेफरेंस आईडी द्वारा 4-चरणीय निवारण प्रगति:
     - `नई समस्या दर्ज` ➔ `कार्यालय जांच` ➔ `संबंधित विभाग को सूचित` ➔ `समाधान संपन्न`
   - नागरिकों की गोपनीयता की पूर्ण सुरक्षा (व्यक्तिगत विवरण सार्वजनिक रूप से प्रकट नहीं किए जाते)।

4. **वार्ड 14 की 7 मुख्य प्राथमिकताएं (Ward Priorities - `/priorities`)**:
   - स्वच्छता, सड़क, सीवरेज, पेयजल, सुरक्षा, प्रकाश एवं नागरिक सहायता केंद्र।

5. **प्रत्याशी परिचय एवं विज़न (Candidate Bio - `/candidate`)**:
   - श्रीमती पूजा मनीष दाधीच का स्थानीय सामाजिक अनुभव एवं वार्ड के प्रति संकल्प।

6. **स्वैच्छिक जनसंवाद व सुझाव (Citizen Feedback - `/feedback`)**:
   - पारदर्शी एवं गैर-बाध्यकारी जनसंवाद (स्पष्ट वैधानिक अस्वीकरण सहित)।

7. **सुरक्षित एडमिन डैशबोर्ड (Admin Portal - `/admin`)**:
   - पासवर्ड एवं सत्र टोकन द्वारा सुरक्षित।
   - सभी शिकायतों की लाइव स्थिति, फिल्टरिंग, स्टेटस अपडेशन एवं आंतरिक टिप्पणियां।

## 🛠️ तकनीकी संरचना (Tech Stack)

- **Frontend / Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Devanagari Typography, Custom Warm Palette (`#FAF6F0`)
- **Icons**: Lucide React
- **Database**: MongoDB (Mongoose ODM) with In-Memory fallback
- **Image Processing / Upload**: Sharp / Cloudinary
- **Deployment**: Vercel / Node.js Production Server

## 🚀 स्थानीय स्तर पर शुरू करें (Local Setup)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/krinectra17-bit/Wardmitra14.git
cd Wardmitra14

# 2. निर्भरताएं इंस्टॉल करें
npm install

# 3. पर्यावरण चर कॉन्फ़िगर करें (.env.local)
cp .env.example .env.local

# 4. डेवलपमेंट सर्वर शुरू करें
npm run dev
```

ब्राउज़र में `http://localhost:3000` पर खोलें।
